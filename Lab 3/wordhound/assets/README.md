# WordHound audio assets

`music/spy-loop.wav` is **Spy Loop** by wipics, downloaded from
<https://opengameart.org/content/spy-loop>. The source labels it CC0/Public
Domain.

`sfx/correct.wav` is a selected confirmation cue from Kenney's **Interface
Sounds** pack, available at <https://kenney.nl/assets/interface-sounds>. That
pack is CC0.

`sfx/listening-start.wav` (`threeTone1`) and `sfx/listening-stop.wav`
(`twoTone1`) are selected turn-boundary cues from Kenney's **Digital Audio**
pack, available at <https://kenney.nl/assets/digital-audio>. That pack is also
CC0.
